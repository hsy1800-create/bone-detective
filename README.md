# 꼬마 뼈 탐정대

와골와골 발굴단 영재 수업 2부(탐구 활동)용 웹앱입니다. 5~6학년 모둠이 패드로 미션을 해결합니다.

- 미션 ① 돋보기 두개골 수사: 흐릿한 두개골 A·B를 돋보기로 살펴 단서 6개 찾기 → 먹이 추리
- 미션 ② 뒤집힌 사건 기록: 이구아노돈의 뿔, 브론토사우루스의 엉터리 머리 → 과학자의 말투
- 미션 ③ 미스터리 동물 사건 파일: 뼈 증거 4장이 하나씩 열리고, 매번 추리와 확신도 기록 → 보고서 → 발표 → 정답 공개

## 깃허브에 올리는 방법 (GitHub Pages)

1. github.com에 로그인한 뒤 오른쪽 위 **+ → New repository**를 누릅니다.
2. 이름을 정하고(예: `bone-detective`) **Public**으로 만든 뒤 **Create repository**를 누릅니다.
3. **uploading an existing file**을 눌러 이 폴더 안의 `index.html`, `README.md`, `fonts` 폴더를 통째로 끌어다 놓고 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**로 가서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://내아이디.github.io/bone-detective/` 주소가 생깁니다. 이 주소를 QR코드로 만들어 아이들 패드에서 열면 됩니다.

## 알아 두기

- 글꼴은 배달의민족 주아체(Jua, SIL Open Font License)를 `fonts` 폴더에 넣어 두었습니다. 인터넷이 막힌 환경에서도 글꼴이 그대로 보입니다.
- 기록은 각 패드 브라우저에만 저장됩니다(서버 없음). 수업이 끝나면 첫 화면 아래 **처음부터 다시 하기(선생님용)**를 두 번 눌러 초기화하세요.
- 모둠마다 사건 파일 번호를 정해 주세요(#1 박쥐, #2 두더지, #3 캥거루는 보너스). 정답은 앱에 드러나지 않고, 발표 후 **정답 공개** 버튼을 눌러야 나옵니다.
